# Blockers and actions left to the user

The core extension has no credential, paid-service, cloud-backend or account blocker.

1. **Install locally.** Version 0.3.0 is loaded unpacked in the user's active Google Chrome profile. The upgrade does not automatically delete any previously archived references. For another browser/profile, run `npm ci && npm run build`; open `chrome://extensions`, enable Developer mode, select **Load unpacked**, and choose `.output/chrome-mv3`. Pin Tab Hub for one-click access.
2. **Keep a private backup.** The profile database survives ordinary restarts but browser-profile deletion, extension removal or disk loss can remove local data. Use **Export** in the hub and store the `.tabhub` file securely; it contains your browsing history and images and is not encrypted. Use **Import** to restore it. Nothing is deleted automatically: only a confirmed Delete permanently action removes local data. Existing backup files are unaffected by later deletion; remove any old backup copies separately if you also want those copies gone. Archives above 500 MB cannot yet be exported/restored in one file; keep the profile intact and arrange a streaming-backup implementation before crossing that limit.
3. **On-device AI is conditional.** The no-op provider ships and the real Chrome `LanguageModel` path is implemented and tested with an API stand-in; an actual downloaded Chrome model was not available in the isolated test browser. Chrome must report `LanguageModel.availability() === "available"` for guesses to appear. No model is downloaded without user action, no page data goes to a hosted AI service, and saving/notes work without it. If your browser does not provide the on-device API/model, there is nothing to configure for the core product; a future opt-in model-download control would improve this optional feature.
4. **Local file pages, if needed.** Chrome may require you to enable **Allow access to file URLs** in this extension's settings before fragment marking works on `file://` pages. Normal HTTP(S) pages need no extra step.
